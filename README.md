# Lindsberg Glutway

The official case file on Lindsberg Glutway, #54, Master of Glut.

A one-page roast site: wanted poster, the evil ways of glut, origin story, FAQ and victim statements. Press **Unleash the Glut**, or type "glut" anywhere on the page.

## Files

- `index.html`: the whole site (HTML, CSS and JS in one file)
- `lindsberg.webp`: the photo
- `face.png`: face close-up used for the small avatars and the falling heads

To view it locally, open `index.html` in a browser.
